A static website prepared for GitHub Pages. Open index.html to view locally. No installation or build process is required.

## Publishing

Create a GitHub repository named minsoo0905.github.io under the minsoo0905 account. Upload the contents of this folder to the repository root. Configure GitHub Pages to publish from the main branch and root folder. The intended address is https://minsoo0905.github.io/.
